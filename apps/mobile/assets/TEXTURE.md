# Light-mode surface texture

`beige-paper.png` was generated with the built-in image-generation tool, copied into this project, and bundled for offline use. It appears at 28% opacity only on light-mode feature cards. Dark mode omits it. No user data or remote image service is involved.

Final prompt:

Use case: photorealistic-natural texture asset. Create a seamless, nearly flat warm off-white paper texture for a premium mobile app surface. Very subtle fine beige cotton-paper grain, low contrast, uniform illumination, no vignette, no objects, no text, no marks, no shadows. Palette only warm ivory #F8F6F1 and faint beige #EEE8DF. Texture must be understated enough to put dark text over it, square crop.
